Resize before compressing

Exact pixel validation usually happens before file-size validation. Make the photo 200 x 230 pixels first so the receiving portal does not reject the file for dimensions.

Then target 50KB if needed

At 200 x 230 pixels many photos are already small, but bright backgrounds or high-quality exports can still exceed 50KB. Compress the resized output with the 50KB target if needed.
