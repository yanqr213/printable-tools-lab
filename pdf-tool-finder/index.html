Common choices

Invoice vs receipt

Use an invoice when you are asking someone to pay. Use a receipt when payment has already happened and you need a record.

One image vs many images

Use the one-page image converter when layout matters on a single sheet. Use multiple images to PDF when each image should become its own page.
