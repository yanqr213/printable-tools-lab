How to use this free PDF tool

  1. Open the Merge PDF Tool and review the example text already in the form.
  2. Replace the sample fields with your own short, accurate wording.
  3. Choose US Letter or A4 before generating if the tool offers paper size options.
  4. Preview the result, then download the PDF and review it before printing, uploading, or sharing.

Create one review file from several smaller PDFs without using a server-side converter.

Privacy and limits

Selected PDF files are read in your browser and are not uploaded by the merge tool.

The free version merges up to six PDFs in one browser session and uses the same daily generation limit as the other tools.

Frequently asked questions

Are my PDFs uploaded?

No. The files are read and merged in your browser for ordinary use.

How many PDFs can I merge?

The free tool accepts up to six PDFs at a time.

Can it merge huge PDFs?

Very large files may be limited by browser memory. Try smaller batches when needed.
