How to use this free image tool

  1. Open the add text to image tool and select one JPG, PNG, or WebP file.
  2. Enter a short main line and optional small line.
  3. Choose a placement, text color, background style, output format, and quality.
  4. Download the new image and check that the text is readable before posting or sharing.
