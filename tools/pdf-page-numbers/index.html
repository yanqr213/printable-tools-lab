Add Page Numbers to PDF

Add simple page numbers to an existing PDF locally in your browser.

Select one PDF, choose a page number position, and download a copy with visible page numbers.

Page numbering is a small but common PDF editing need for handouts, packets, reports, client drafts, and merged documents.

Open generator

How to use this free PDF tool

  1. Open the Add Page Numbers to and review the example text already in the form.
  2. Replace the sample fields with your own short, accurate wording.
  3. Choose US Letter or A4 before generating if the tool offers paper size options.
  4. Preview the page, then download the PDF and review it before printing or sharing.

Good use cases

Meeting packet

Add page references before sharing a PDF handout.

Classroom packet

Number pages so students and teachers can refer to the same page quickly.

Merged PDF cleanup

Add simple numbers after combining several files into one PDF.

Privacy and limits

The PDF is read and numbered in your browser without uploading the file to PrintableTools Lab.

The free version adds simple page numbers to one PDF and uses the same daily generation limit as the other tools.

Frequently asked questions

Can I choose the position?

Yes. Use bottom center, bottom right, or top right.

Does this edit the original file?

No. It downloads a new numbered copy.

Are files uploaded?

No. The page numbering runs in your browser for ordinary use.
